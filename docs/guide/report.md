# Report a problem

1. Search the open and closed
   [issues](https://github.com/viell-dev/slop-calc-sheet-manager/issues): the problem may already be
   known. [Issue #33](https://github.com/viell-dev/slop-calc-sheet-manager/issues/33) lists defects
   in LibreOffice itself that affect Sheet Manager.
2. Open a
   [bug report](https://github.com/viell-dev/slop-calc-sheet-manager/issues/new?template=bug.yml).
   It asks for:
   - the Sheet Manager version, from **Tools ▸ Extension Manager**;
   - LibreOffice's version information: in **Help ▸ About**, select **Copy Version Information**
     and paste it. It includes the operating system and the user interface (the "VCL" line);
   - how LibreOffice was installed;
   - the steps, from opening the workbook to the problem;
   - what happened and what you expected;
   - a small workbook made for the report.

Never attach a real workbook, or a screenshot of one with private content. Make a workbook with
made-up sheet names and data that shows the same problem.

Ideas for improvements and new features have their own
[forms](https://github.com/viell-dev/slop-calc-sheet-manager/issues/new/choose). Report a security
vulnerability privately, as the
[security policy](https://github.com/viell-dev/slop-calc-sheet-manager/blob/main/SECURITY.md)
describes.

Sheet Manager is maintained by AI agents. They read every report, reproduce it, and say on the
issue what they found.
