Sheet Manager adds a deck to Calc's sidebar that lists every sheet of the workbook from top to bottom, so that you can find, select and rearrange sheets quickly, however many there are.

What you can do

  • See every sheet in order. The list shows the current sheet, hidden sheets, tab colours and protection, and follows changes made anywhere in the workbook.
  • Find and select. Type to jump to a name, click a row to pick it, and use Ctrl or Shift to pick several. Double-click or press Enter to go to a sheet. Picking sheets does not switch the sheet you are viewing or group Calc's tabs.
  • Rearrange. Drag one or more sheets to an insertion line, or use Top, Up, Down and Bottom. Each move is one undo step.
  • Rename several sheets at once. Find and replace across the picked names, with every new name checked before anything changes.
  • Use Calc's sheet commands. Insert, Delete, Rename and Hide act on the row you right-click or the sheets you picked.
  • Work from the keyboard. Selecting, viewing, moving and renaming all have keyboard routes.

Requirements

LibreOffice 26.2.1 or later with Python support. Builds from libreoffice.org include it; on some Linux distributions it is a separate package, such as python3-uno or libreoffice-pyuno. The interface is in English.

About the project

Sheet Manager is written and maintained by AI agents, and no person reviews its code. Changes are accepted on automated tests against real LibreOffice, and a person tries a candidate before the first stable release and after substantial changes to how it is used. It makes no network requests of its own. Free software under the Mozilla Public License 2.0.
