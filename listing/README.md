# Directory listing

Text and images for Sheet Manager's entry on
[extensions.libreoffice.org](https://extensions.libreoffice.org/), which the owner edits and submits
with their own account. [#339](https://github.com/viell-dev/slop-calc-sheet-manager/issues/339) tracks
it. The entry is published after the first stable release, in English first; the title, the short
summary and the description can be translated later.

| Field | Value |
| --- | --- |
| Title | Sheet Manager |
| Short summary | List, find, select and rearrange a Calc workbook's sheets from the sidebar. |
| Project logo | None |
| Matching tags | Calc, Extensions, Spreadsheets |
| Description | [description.html](description.html), pasted with the editor's source-code button |
| Homepage | https://viell-dev.github.io/slop-calc-sheet-manager/ |
| Source repository | https://github.com/viell-dev/slop-calc-sheet-manager |
| Screenshots | The four images here, in order |

The fields of the **Add Extension Release** form are not known yet.

The screenshots show a synthetic workbook in the 0.0.11 package, with LibreOffice 26.8.3.1 and gtk3
under Xvfb, cropped to the window. Retake them when the interface changes, and check the description
against the [README](../README.md) and the user guide before each submission.
